datasheet-skills

Map a datasheet PDF, then write one lookup skill per selected section or peripheral. Page numbers are PDF indexes (pdftotext -f), not printed page numbers.

Args and self-check

  • Required: args.pdf, args.part (2–24, used in skill names).
  • Defaults: skills_dir=.grok/skills, max_skills=36 (1–48), split_pages=90 (20–400), min_pages=2 (1–30).

Phase · Outline · agent “outline” · execute

Read the PDF outline

  • pdfinfo for the page count. qpdf --json --json-key=outlines for destinations.
  • Keep depth 0 and depth 1 only (≤180). Drop depth 2+; those stay inside the parent skill.
  • Each entry: number, title, slug, kind, start_page.
  • Kinds: section, peripheral, container, skip.
  • Empty outline: return no entries. Do not guess pages.
complete

No usable outline

No entries, or no page count. Also exits if every entry fails the checks below.

script

Build the catalog

  • Drop bad numbers, titles, pages past the count, empty slugs, and duplicates.
  • Sort by start page, then shallower heading first.
  • End page is the page before the next heading at the same or shallower depth.
Phase · Select · agent “classify” · read-only

Relabel every heading

No tools. One label per outline number. May correct the slug. On failure, keep the outline kinds.

  • peripheral — a named block (UART, DMA, PIO, clocks, bootrom, …). Never split.
  • container — a heading that only groups blocks, such as “Peripherals”. Dropped; children become skills.
  • skip — legal, TOC, history, units, register-field glossary.
  • section — intro, bus, processor, electrical, errata, and other chapters.
script · select_roots

Pick the skills

  • Walk depth-0 roots. Explode a node when the side rules say so, and collect the children instead.
  • Keep section and peripheral. Drop skip, leftover container, and sections shorter than min_pages.
  • Rename slug datasheet to overview. Deduplicate slugs with n12-1 style fallbacks.
  • Order peripherals first, then sections by longest span.
  • Cap at max_skills and at agent budget: each kept block costs two later agents (write + verify), leaving one slot for the index.
  • Skill name {part}-{slug}, directory {skills_dir}/{part}-{slug}. Names longer than 64 characters are cut.
complete

Nothing selected

No section or peripheral survived the filters and the cap.

await_user · user

Confirm the plan

Writes catalog.md and pauses: “Write N skills under {skills_dir}?” Resume continues. Stop the run to change args.

Phase · Write · parallel · capability all

One writer per chosen block

  • May run pdftotext, pdfinfo, and mkdir. Writes only SKILL.md in its directory.
  • Reads the range in windows of at most 25 pages. Confirms the heading is on start_page.
  • Lookup procedure, not a copy of the datasheet. At most 12 short facts. Under 160 lines.
  • Returns wrote and heading_seen. A writer with an empty heading is not verified.
Phase · Verify · parallel · capability all, prompt forbids edits

Adversarial check

  • File exists and frontmatter name matches.
  • pdftotext -layout -f START -l START shows the heading. Printed page numbers do not count.
  • Skill tells the agent to extract that range. Under 160 lines. No copied paragraph or register-description table.
  • Accept only when accept is true and evidence contains the start-page digits.
  • Missing writer, failed verifier, or evidence without the page digits → rejected.
Phase · Index · agent “index” · read-write

Router skill

Runs only when at least one skill was accepted and {part}-datasheet is at most 64 characters. Does not read the PDF. Writes only {skills_dir}/{part}-datasheet/SKILL.md: child names, outline numbers, titles, kinds, and page ranges. Under 220 lines.

complete

Report

report.md lists accepted paths and rejected reasons. Result: accepted count, rejected count, PDF, part, router path.

When a heading explodes

should_explode replaces a heading with its depth+1 children.

  1. Never explode peripheral or skip.
  2. Count substantial children: every peripheral, plus sections at least min_pages long.
  3. No substantial children → keep the parent.
  4. container always explodes.
  5. Any peripheral child → explode.
  6. A depth-0 section longer than split_pages with at least two substantial children → explode.
